# pbswi-core-skills

Crucial, daily-driver skills — original or adapted with citations — that make life easier working in public media.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on `public-media-work/pbswi-core-skills` via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` plus `docs/adr/` at the repo root, created only when needed. See `docs/agents/domain.md`.
